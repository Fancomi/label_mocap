SMPL 工具集

浏览器内运行 · 数据全程留在本地,不上传 · 多人同时使用互不影响

🏷 标注器 Annotator

增删改 SMPL 姿态 / 位置 / 体型 / 2D 框,支持图像序列与视频,原地保存 JSON。建议用 Chrome / Edge。

👁 查看器 Viewer

只读播放 SMPL 数据,2D 对齐 / 3D 自由视角。可加载标注器产出的 JSON。

🟢 点云标注器 PCD Annotator

3D LiDAR 点云 + SMPL 标注,纯本地。多种点云配色、上轴/前轴切换,Root/姿势/IK/体型编辑。建议用 Chrome / Edge。

标注器原地保存的 player_0.json 与查看器读取的格式一致 —— 标完即可在查看器中加载查看。 原地保存(写回所选目录)需要 Chrome / Edge 的文件系统访问能力;其他浏览器为下载模式。
